Раздел I Основные правила сервера

Основные правила

1.1 - Все пользователи, находящиеся на нашем Discord-сервере и пользующиеся нашими услугами, автоматически соглашаются со всеми правилами этого проекта.
  • Незнание правил не освобождает от получения наказаний. Правила действуют на любые текстовые сообщения, голосовые каналы и вложения (файлы, изображения, GIF, текстовые документы, звуки и другие материалы);
  • Правила распространяются также на весь персонал сервера. Персонал сервера получает наказания особого характера.
1.2 - Наказания за нарушение правил сервера включают следующие типы ограничений:
  • Устное предупреждение: Не имеет ограничений и действуют только лишь в качестве предупреждения;
  • Тайм-аут (мьют): Блокировка доступа к текстовым и голосовым каналам;
  • Бан: Блокировка доступа ко всему основному серверу;
  • Система автомодерации (предупреждения): Автоматическая система JuniperBot, модерирующая сервер в автономном режиме;
  • Внос в ЧС: Исходя из типа ЧС — запрет на использование опредленных отраслей сервера. Может быть выдана за нарушение любых правил сервера.
1.2.1 - Проверка профиля с помощью автоматической системы RegeX:
  • Данная система автоматически проверяет наличие запрещенных символов в отображаемом никнейме и теге;
  • Разрешенными символами является строчный и заглавный латинский алфавит (A-z), строчный и заглавный алфавит кириллицы (А-я), арабские цифры, символы ` ~ ! @ # $ % ^ & * ( ) _ + = - } { " : ? > < [ ] ' ; . / \ | №, а также пробел;
  • Изначально теги не должны попадать под фильтрацию этой системы, однако Discord все равно проверяет наличие запрещнной информации в теге. Поэтому, некоторые эмодзи (или сам текст) в тегах клана могут быть раздражителем, так как эмодзи всегда имеет свою кодировку.
1.3 - Запрещается использование неточностей в правилах сервера или самом сервере для причинения вреда серверу или участникам, получения выгоды для себя или других, а также для иных нежелательных действий.
  • Данный пункт влияет на все ответвления сервера.
Наказание: Блокировка на срок, зависящий от причинённого неудобства для сервера.
ToS 1.4 - Запрещается нарушать любые правила компании Discord, включая условия предоставления сервисов Discord, политику конфиденциальности и правила сообщества.
Наказание: Соответствующее из правил Discord.
ToS 1.4.1 - Запрещается использование приложения Discord в юном возрасте (до 13 лет).
Наказание: Соответствующее из правил Discord.
ToS 1.4.2 - Запрещается использование сторонних модификаций для Discord, изменяющих его работу и предоставляющих возможности, недоступные обычным пользователям.
  • Запрет распространяется только на модификаторы, позволяющие просматривать скрытые каналы или изменять дизайн Discord нереалистичным образом.
Наказание: Соответствующее из правил Discord.

Наказание: Блокировка на срок, зависящий от причинённого неудобства для сервера.

  • Публикация разрешена только если администрация явно указала, что информация не является закрытой;
  • Данный пункт влияет на всевозможные способы передачи информации.
Наказание: Блокировка до 180 дней.

Наказание: Блокировка до 60 дней.

  • Запрещено подстрекать пользователей к использованию читов или получению вреда от читерства;
  • Упоминание любых читерских ПО наказываться тайм-аутом до 12 часов.
Наказание: Блокировка на 90 дней.

  • Пункты, которые действуют на личные сообщения: 1.6 2.1 2.1.1 2.1.2 2.2 2.8

Права персонала

P-1 - Права администраторов:
  • К администрации сервера относится: Server Owner, Server Leader, Server Manager, Administrator, Mod Manager и Event Manager;
  • По отношению к правилам сервера, администратор имеет право пренебречь правилам сервера, если для решения какой-либо проблемы необходимы действия, которые могут перечить правилам;
  • По отношению к исполнению должностных обязанностей типа: модерирование сервера, регулировка действий персонала, администратор имеет право изменить время наказаний, указанного в пункте или ослушаться регламентов;
  • Администратор не имеет права (в рамках сервера) относится ко всем участникам сервера по разному. Т.е, все участники по отношению к администрации должны находиться на равне.
P-2 - Права модераторов:
  • К членам модераторского состава относится: Expert Moder, Advanced Moder, Moder и Helper;
  • По отношению к правилам сервера, модерация не имеет право пренебрегать правилам сервера, однако по указанию/решению администрации, пренебречь можно;
  • По отношению к исполнению должностных обязанностей: модератор обязан выдавать наказания, если он это увидел (исключение - P. Moder), после чего, составить отчет о выданном наказании. При необходимости, возможность предъявить доказательство на выданное наказание в течении 2-х недель с момента выдачи наказания. В исключение так же входит нерабочее время сотрудника (отгулы, отпуски);
  • Модератор не имеет права (в рамках сервера) относится ко всем участникам сервера по разному. Т.е, все участники по отношению к модераторам должны находиться на равне.
P-2 - Права организаторского состава:
  • К членам организаторского состава относятся: Alt. Event Manager, Active Event Organizer и Trainee Event Organizer;
  • По отношению к правилам сервера, организаторский состав не имеет права пренебречь любым правилам сервера;
  • По отношению к исполнению должностных обязанностей: организатор обязан выполнять свою еженедельную норму (исключение - отгулы, отпуски);
  • Организаторский состав не имеет права (в рамках сервера) относится ко всем участникам сервера по разному. Т.е, все участники по отношению к организаторам должны находиться на равне.

4.1 - Правила публикации отзывов:
  • IND Отзыв должен содержать только один тег со звездами.
  • Разрешается создавать отзывы только о персонале сервера и о самом сервере.
  • Отзыв должен содержать хотя бы малейшую информацию поставленных звезд.

4.3 - Правила экономики JuniperBot:
  • Запрещено использование багов или других ошибок для получения выгоды для себя, других пользователей или вреду участникам/серверу/экономики.
